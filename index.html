1. VirtualBox Disk Image Manifest (Drive D:\)

The following three virtual disk images (.vdi) exist in your host machine directory D:\. Each disk image must be attached to the respective VirtualBox virtual machine and SATA Controller port:

VDI Image File Target VirtualBox VM File Size on D:\ Controller VirtualBox SATA Port Environment Role
DESKTOP-IMQ5TKS-0.vdi Siemens Test 118,427,648 KB (~118 GB) Controller: SATA (AHCI) SATA Port 0 (Boot) Primary OS Boot Disk containing TIA Portal, STEP 7, WinCC, and engineering licenses.
DESKTOP-IMQ5TKS-1.vdi Siemens Test 1,187,840 KB (~1.2 GB) Controller: SATA (AHCI) SATA Port 1 (Data) Secondary data disk / dedicated project workspace partition.
NewWin7Pro32.vdi Win 7 62,820,352 KB (~62.8 GB) Controller: SATA (AHCI) SATA Port 0 (Boot) Standalone Windows 7 Professional 32-bit legacy tooling environment.
VirtualBox Storage Principle: VirtualBox accesses VDI files directly at their absolute paths. Ensure the drive letter D:\ remains unchanged on your Windows host.

4. Step-by-Step VirtualBox 7.x Setup Walkthrough

1
Create New Virtual Machine Shell in VirtualBox 7

In Oracle VM VirtualBox Manager:

  • Click the blue New icon (Ctrl+N).
  • Name: Enter Siemens Test.
  • ISO Image: Leave empty. Check "Skip Unattended Installation" if prompted.
  • Type: Select Microsoft Windows.
  • Version: Select Windows 10 (64-bit) or Windows 11 (64-bit).
  • Under Virtual Harddisk: Select "Do not add a virtual hard disk".
  • Click Finish / Create (Confirm the prompt about starting with no virtual hard disk).
2
Configure System & Display Properties (Eliminate Warning)

Select Siemens Test and click the orange Settings gear icon (Ctrl+S):

  • System → Motherboard: Set Base Memory to 8,192 MB (8 GB) or 12,288 MB (12 GB).
  • System → Processor: Set Processors slider to 4 vCPUs (ensure slider remains in the green zone).
  • Display → Screen: Set Video Memory to maximum 128 MB and check Enable 3D Acceleration.
Why you saw "Invalid settings detected ⚠️": In VirtualBox 7, allocating less than 128 MB Video Memory or exceeding host physical CPU core limits triggers the bottom alert. Setting Video Memory to 128 MB resolves this immediately.
3
Set SATA Controller Port Count to 4

Go to Settings → Storage:

  • Under Storage Devices, select Controller: SATA.
  • In the right Attributes pane, change Port Count from 2 or 3 to 4.
  • Verify Type is set to AHCI.
Port Allocation: Setting Port Count to 4 provides enough ports for Disk 0, Disk 1, and the Optical Disc drive without SATA bus conflicts.
4
Attach Primary (-0.vdi) and Secondary (-1.vdi) Disks

Under Controller: SATA, attach both virtual disk files in exact sequence:

  • Click the Adds Hard Disk icon () next to Controller: SATA.
  • Click Add and browse to:
    D:\DESKTOP-IMQ5TKS-0.vdi → Click Choose. Verify it connects to SATA Port 0.
  • Click Adds Hard Disk again → Click Add and browse to:
    D:\DESKTOP-IMQ5TKS-1.vdi → Click Choose. Verify it connects to SATA Port 1.
  • Leave Empty (Optical Drive) attached to SATA Port 2.
VIRTUALBOX SATA STORAGE TOPOLOGY
Controller: SATA (AHCI, Port Count: 4) ├── [SATA Port 0] D:\DESKTOP-IMQ5TKS-0.vdi (118,427,648 KB) -> Primary Boot OS ├── [SATA Port 1] D:\DESKTOP-IMQ5TKS-1.vdi (1,187,840 KB) -> Secondary Data Drive └── [SATA Port 2] Empty (Optical CD/DVD Drive)
5
Configure Bridged Networking for Industrial PLC & TIA Portal

Go to Settings → Network:

  • Enable Adapter 1.
  • Attached to: Select Bridged Adapter.
  • Name: Select your laptop's physical Ethernet RJ45 network interface (e.g. Intel Ethernet Connection or Realtek PCIe GBE).
  • Expand Advanced: Set Promiscuous Mode: Allow All (required for TIA Portal PG/PC interface broadcast discovery of S7-1200 / S7-1500 PLCs).
  • Click OK to save all settings.
1
Create VirtualBox Windows 7 (32-bit) Container

In Oracle VM VirtualBox Manager:

  • Click New (Ctrl+N).
  • Name: Enter Win 7.
  • Type: Select Microsoft Windows.
  • Version: Select Windows 7 (32-bit).
  • Under Virtual Harddisk, select "Do not add a virtual hard disk".
  • Click Finish.
2
Configure 32-Bit System & Graphics Settings

Click Settings gear (Ctrl+S):

  • System → Motherboard: Set Base Memory to 3,072 MB (3 GB) or 4,096 MB (4 GB).
  • System → Processor: Allocate 2 vCPUs.
  • Display → Screen: Set Video Memory to 128 MB.
3
Attach NewWin7Pro32.vdi & Fix Yellow Warning Icon

Go to Settings → Storage:

  • Select Controller: SATA (Port Count: 2).
  • Click Adds Hard Disk → Click Add → Select D:\NewWin7Pro32.vdi (62,820,352 KB).
  • Click Choose to attach to SATA Port 0.
How to fix the Yellow ⚠️ Warning on NewWin7Pro32.vdi:
If VirtualBox displays a yellow triangle next to NewWin7Pro32.vdi in the Storage Devices tree, it means the disk reference was broken during a previous import or drive letter change.
Fix: Click on the warning entry, click the Remove Attachment (red minus/X) icon below the tree, then click Adds Hard Disk and re-select D:\NewWin7Pro32.vdi.

6. VirtualBox Industrial Network Setup (Siemens S7 & TIA Portal)

Configuring VirtualBox for Real PLC Hardware Communication

When running TIA Portal or STEP 7 inside VirtualBox, standard NAT networking will block PLC discovery packets (DCP / LLDP). Follow these network rules:

Network Topology VirtualBox Setting Use Case & Behavior
Physical PLC Online Access (S7-1200 / S7-1500 / ET200) Bridged Adapter → Select physical RJ45 LAN card → Promiscuous: Allow All The VM appears as a direct physical device on the factory subnet with its own dedicated IP address.
Offline Simulation Only (PLCSIM / Virtual HMI) Host-Only Adapter → VirtualBox Host-Only Ethernet Adapter Isolates VM communication to your host PC without needing an external network cable.

7. Procedure: Attaching a Folder from Host PC to VM (Shared Folders)

Use VirtualBox Shared Folders to seamlessly exchange TIA Portal project archives (.zap16 / .zap17 / .zap18), license keys, GSDML files, software installers, and project documentation between your physical host computer (e.g. C:\Users\jingsian.chin\Desktop\porject\win7) and the virtual machine without needing physical USB flash drives.

1
Add the Host Folder in VirtualBox VM Settings (Matching Your Screen)

Configure the shared folder path in VirtualBox settings (as shown in your Settings → Shared Folders screen):

  • In VirtualBox Manager, select your virtual machine and click Settings (Ctrl+S).
  • Click Shared Folders in the left navigation sidebar.
  • Click the Add Shared Folder icon ( folder with green plus) on the right.
  • In the Add Share dialog box, configure the parameters as follows:
    • Folder Path: Click dropdown → select Other... → browse to your host folder (e.g. C:\Users\jingsian.chin\Desktop\porject\win7).
    • Folder Name: win7 (or any identifier like Host_Shared).
    • Read-only: UNCHECKED (Allows Full Access so the VM can read and save files directly to the host PC).
    • Auto-mount: CHECKED (Automatically assigns a network drive letter upon VM boot).
    • Mount point: Enter Z: (or leave blank for automatic drive letter assignment).
    • Make Permanent: CHECKED (Places the share under Machine Folders so it persists across VM reboots).
  • Click OK and then click OK to save VM settings.
2
Access the Attached Folder inside the Virtual Machine

Inside your running Windows VM:

  • Open This PC / My Computer.
  • Under Network Locations, you will see your shared folder mounted as win7 (\\VBOXSVR) (Z:).
  • Any file copied into this folder on your main computer instantly appears inside the VM, and vice versa!
CMD MANUAL MOUNT COMMAND (IF DRIVE DOES NOT APPEAR AUTOMATICALLY)
# Run inside VM Command Prompt (CMD) net use Z: \\VBOXSVR\win7 /persistent:yes
3
Bonus: Enable Bidirectional Copy/Paste & Drag-and-Drop

For instant drag-and-drop between Host Desktop and VM Desktop:

  • In VM Settings (Ctrl+S) → General → Advanced:
    • Set Shared Clipboard: Bidirectional
    • Set Drag'n'Drop: Bidirectional
  • Click OK. You can now copy text, IP addresses, and drag files directly across the two desktop screens.

8. VirtualBox Troubleshooting & Error Resolutions

⚠️ Fix: Yellow Warning Icon ⚠️ on NewWin7Pro32.vdi in Storage Settings

Cause: In Screenshot 2, VirtualBox has lost the direct binding to D:\NewWin7Pro32.vdi or the registry UUID is stale.

Resolution Steps in VirtualBox:

  1. In VirtualBox main window, click File → Virtual Media Manager (Ctrl+D).
  2. Under Hard Disks, locate NewWin7Pro32.vdi.
  3. Click Release, then click Remove (select "Keep" — do NOT select Delete).
  4. Open Win 7 VM → Settings → Storage.
  5. Under Controller: SATA, click Adds Hard Disk → Click Add → Browse to D:\NewWin7Pro32.vdi → Click Choose → Click OK.
⚠️ Fix: "Invalid settings detected ⚠️" at Bottom of Siemens Test Settings

Resolution Steps in VirtualBox:

  • Step 1: In Siemens Test Settings, go to Display → Screen.
  • Step 2: Drag the Video Memory slider all the way to 128 MB.
  • Step 3: Check the box for Enable 3D Acceleration.
  • Step 4: Check System → Processor: Ensure CPU count is 4 and within the green bar.
  • Step 5: Look at the bottom of the window: the "Invalid settings detected" warning will disappear immediately. Click OK.
🔑 Fix: "Cannot register hard disk ... UUID already exists"

If VirtualBox rejects attaching the disk due to a duplicate UUID conflict, open PowerShell as Administrator and run:

POWERSHELL (ADMIN) — VIRTUALBOX UUID RESET
cd "C:\Program Files\Oracle\VirtualBox" # Reset UUID for Win 7 VDI .\VBoxManage.exe internalcommands sethduuid "D:\NewWin7Pro32.vdi" # Reset UUID for Siemens VDIs .\VBoxManage.exe internalcommands sethduuid "D:\DESKTOP-IMQ5TKS-0.vdi" .\VBoxManage.exe internalcommands sethduuid "D:\DESKTOP-IMQ5TKS-1.vdi"

10. VBoxManage CLI Automation Reference

VBOXMANAGE COMMAND SHORTCUTS
# 1. Start Siemens VM in standard GUI mode VBoxManage startvm "Siemens Test" --type gui # 2. Start Windows 7 VM in standard GUI mode VBoxManage startvm "Win 7" --type gui # 3. Add Shared Folder via CLI directly VBoxManage sharedfolder add "Siemens Test" --name "win7" --hostpath "C:\Users\jingsian.chin\Desktop\porject\win7" --automount # 4. Attach VDI directly via CLI (Alternative to GUI) VBoxManage storageattach "Siemens Test" --storagectl "SATA" --port 0 --device 0 --type hdd --medium "D:\DESKTOP-IMQ5TKS-0.vdi" VBoxManage storageattach "Siemens Test" --storagectl "SATA" --port 1 --device 0 --type hdd --medium "D:\DESKTOP-IMQ5TKS-1.vdi" VBoxManage storageattach "Win 7" --storagectl "SATA" --port 0 --device 0 --type hdd --medium "D:\NewWin7Pro32.vdi" # 5. List all registered virtual machines VBoxManage list vms
